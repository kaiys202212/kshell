# kshell 桌面版冒烟清单

桌面版（Wails）发布前在 **Windows 本机** 跑一遍；每条按「前置 → 步骤 → 预期」执行。

## 前置

```powershell
.\build.ps1 -Desktop     # 产物 dist\kshell-desktop.exe
.\dist\kshell-desktop.exe
```

## 内嵌终端（中心区，2026-09-28 起为「恢复」默认路径）

- [ ] **恢复会话进中心区终端并能交互**
  - 前置：至少 claude / codex 两种工具各一条可恢复会话；本机工具已安装
  - 步骤：点会话行「恢复」→ 中心区出现以会话标题命名的页签 → 在终端里输入一句话回车
  - 预期：页签自动激活；TUI 正常渲染（颜色/边框/光标正常，无乱码）；输入有回显、回答正常流式输出

  - 步骤：在中心区页签条上来回切换；切走再切回
  - 预期：切换即时；切回后屏幕内容与光标位置保持（不重新拉取、不闪白）；页签上工具徽标正确
- [ ] **同一会话重复「恢复」不重复起进程**
  - 步骤：对已开终端的会话行再点一次「恢复」（按钮文案应为「切换」）
  - 预期：不新开页签/进程，直接切到已有终端页签
- [ ] **终端尺寸随面板变化**
  - 步骤：拖动左右两栏分隔条挤压/放宽中心区；把窗口最大化再还原
  - 预期：终端行列跟随重排（TUI 自适应，无错行/串行）；拖动分隔条全程跟手、无卡顿
- [ ] **关闭终端页签结束进程**
  - 步骤：关闭某终端页签；任务管理器查看 node/claude 进程
  - 预期：页签消失、退回预览页签；**重点确认没有残留的 node/claude 子进程**（`cmd.exe /c` 包装的孙进程终止是已知薄弱点，若残留请记录）
- [ ] **关闭工作区页签连带结束该工作区终端**
  - 步骤：某工作区开着终端时关闭它的标题栏页签

- [ ] **终端退出提示**
  - 步骤：在终端里输入 `exit`（或 Ctrl+D）结束 CLI
  - 预期：终端顶部出现「会话已退出（退出码 0）」状态条；此时点会话行「恢复」可在原地重启该终端

## 外部终端窗口（已下线，2026-09-29）

会话行右侧图标按钮与工具菜单里的「在外部终端打开」**已全部移除**：该路径走 `cmd /c start` 弹独立系统
控制台窗口，正是「新建会话时不断弹黑窗」的来源，且与内嵌终端入口语义重复。

Go 侧 `NewSessionWithTool` / `ResumeSession` / `FocusSession` 绑定与 `window_win` 的启动逻辑仍保留，
将来若要恢复该功能，建议带二次确认并明确提示「会弹出独立终端窗口」。

## 回归口径

- `go vet` 交叉口径为 **windows + linux** 两平台：
  ```powershell
  go vet ./...
  $env:GOOS='linux'; go vet ./...; Remove-Item Env:GOOS
  ```
- **darwin 不做 Windows 交叉验证**：托盘库 energye/systray 的 darwin 后端强依赖 cgo，Windows 上 `GOOS=darwin CGO_ENABLED=0 go vet` 恒红属于已知限制；darwin 只能在真机（开 CGO，装 Xcode 命令行工具）上构建与验证。
