# kshell 桌面版冒烟清单

桌面版（Wails）发布前在 **Windows 本机** 跑一遍；每条按「前置 → 步骤 → 预期」执行。

## 前置

```powershell
.\build.ps1 -Desktop     # 产物 dist\kshell-desktop.exe
.\dist\kshell-desktop.exe
```

## 内嵌终端（中心区，2026-09-28 起为「恢复」默认路径）

- [ ] **恢复会话进中心区终端并能交互**
  - 前置：至少 claude / codex 两种工具各一条可恢复会话；本机工具已安装
  - 步骤：点会话行「恢复」→ 中心区出现以会话标题命名的页签 → 在终端里输入一句话回车
  - 预期：页签自动激活；TUI 正常渲染（颜色/边框/光标正常，无乱码）；输入有回显、回答正常流式输出
- [ ] **多会话快捷切换**
  - 前置：已用 3 条不同会话各开一个终端页签
  - 步骤：在中心区页签条上来回切换；切走再切回
  - 预期：切换即时；切回后屏幕内容与光标位置保持（不重新拉取、不闪白）；页签上工具徽标正确
- [ ] **同一会话重复「恢复」不重复起进程**
  - 步骤：对已开终端的会话行再点一次「恢复」（按钮文案应为「切换」）
  - 预期：不新开页签/进程，直接切到已有终端页签
- [ ] **终端尺寸随面板变化**
  - 步骤：拖动左右两栏分隔条挤压/放宽中心区；把窗口最大化再还原
  - 预期：终端行列跟随重排（TUI 自适应，无错行/串行）；拖动分隔条全程跟手、无卡顿
- [ ] **关闭终端页签结束进程**
  - 步骤：关闭某终端页签；任务管理器查看 node/claude 进程
  - 预期：页签消失、退回预览页签；**重点确认没有残留的 node/claude 子进程**（`cmd.exe /c` 包装的孙进程终止是已知薄弱点，若残留请记录）
- [ ] **关闭工作区页签连带结束该工作区终端**
  - 步骤：某工作区开着终端时关闭它的标题栏页签
  - 预期：该工作区所有内嵌终端页签消失；对应进程结束
- [ ] **终端退出提示**
  - 步骤：在终端里输入 `exit`（或 Ctrl+D）结束 CLI
  - 预期：终端顶部出现「会话已退出（退出码 0）」状态条；此时点会话行「恢复」可在原地重启该终端

## 外部终端窗口（次要入口：会话行右侧图标按钮）

- [ ] **多开 3 个不同工具会话窗口互不影响**
  - 前置：至少 3 个不同工具（claude / codex / gemini）的可恢复会话；本机工具已安装
  - 步骤：依次点击三条不同工具的会话行右侧「在外部终端打开」图标；在三个弹出的终端窗口里分别执行命令
  - 预期：弹出 3 个独立终端窗口，标题各不相同（`kshell · <会话标题>`）；各窗口输入输出互不串扰，关闭其一不影响其余两个
- [ ] **最小化的会话窗口点击后拉回前台**
  - 前置：已恢复至少一个会话，其终端窗口已最小化到任务栏
  - 步骤：在 kshell 窗口再次点击该会话行右侧的外部终端图标
  - 预期：最小化窗口被还原并置前，不弹出第二个同名窗口
- [ ] **同一会话重复点击不弹新窗**
  - 前置：已恢复一个会话
  - 步骤：连续快速点击同一会话行右侧图标多次（含窗口创建中的瞬间连点）
  - 预期：始终只有一个对应标题的终端窗口；创建中重复请求被忽略、创建完成后重复请求转为聚焦
- [ ] **窗口关闭后前端行状态还原（window:closed）**
  - 前置：已恢复一个会话，前端对应行显示「已打开」状态
  - 步骤：手动关闭该终端窗口，回到 kshell 等待 5~8 秒（回收宽限期 3s + 轮询间隔 2s）
  - 预期：前端该行的 open 状态自动还原为「未打开」，无需手动刷新

## 兼容性

- [ ] **WT 未安装回退 PowerShell**
  - 前置：模拟 Windows Terminal 缺失。**注意：仅从 PATH 剔除 WindowsApps 目录无效**——`findWt()` 在 LookPath 失败后还会回退探测 `%LOCALAPPDATA%\Microsoft\WindowsApps\wt.exe`，该路径不受 PATH 影响。有效做法是临时重命名 wt.exe（验证后还原）：
    ```powershell
    Rename-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\wt.exe" wt.exe.bak
    .\dist\kshell-desktop.exe
    # 验证完毕后：
    Rename-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\wt.exe.bak" wt.exe
    ```
    （若 wt.exe 在 PATH 的其他位置，需一并重命名或临时剔除对应目录。）
  - 步骤：在上述环境中恢复任一会话
  - 预期：弹出的是 PowerShell 窗口（非 WT），会话正常启动；还原 wt.exe 后再恢复，弹回 WT 窗口
- [ ] **深浅色主题**
  - 步骤：Windows 设置里切换深色/浅色模式，重启应用；前端界面里若有主题跟随设置也一并切换
  - 预期：两种模式下界面配色正常、无不可读的对比度问题；托盘图标在两种模式下均可见
- [ ] **TUI 照常可用**
  - 步骤：
    ```powershell
    go build ./cmd/kshell
    .\kshell.exe
    ```
  - 预期：TUI 正常启动，Sessions / Files / Remote 三视图可切换，恢复会话仍走 TUI 内嵌终端（与桌面版弹窗互不影响）

## 回归口径

- `go vet` 交叉口径为 **windows + linux** 两平台：
  ```powershell
  go vet ./...
  $env:GOOS='linux'; go vet ./...; Remove-Item Env:GOOS
  ```
- **darwin 不做 Windows 交叉验证**：托盘库 energye/systray 的 darwin 后端强依赖 cgo，Windows 上 `GOOS=darwin CGO_ENABLED=0 go vet` 恒红属于已知限制；darwin 只能在真机（开 CGO，装 Xcode 命令行工具）上构建与验证。
