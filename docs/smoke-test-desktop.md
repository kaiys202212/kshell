# kshell 桌面版冒烟清单

桌面版（Wails）发布前在 **Windows 本机** 跑一遍；每条按「前置 → 步骤 → 预期」执行。

## 前置

```powershell
.\build.ps1 -Desktop     # 产物 dist\kshell-desktop.exe
.\dist\kshell-desktop.exe
```

## 会话窗口

- [ ] **多开 3 个不同工具会话窗口互不影响**
  - 前置：至少 3 个不同工具（claude / codex / gemini）的可恢复会话；本机工具已安装
  - 步骤：依次点击三条不同工具的会话行「恢复」；在三个弹出的终端窗口里分别执行命令
  - 预期：弹出 3 个独立终端窗口，标题各不相同（`kshell · <会话标题>`）；各窗口输入输出互不串扰，关闭其一不影响其余两个
- [ ] **最小化的会话窗口点击后拉回前台**
  - 前置：已恢复至少一个会话，其终端窗口已最小化到任务栏
  - 步骤：在 kshell 窗口再次点击该会话行的「恢复」（或聚焦按钮）
  - 预期：最小化窗口被还原并置前，不弹出第二个同名窗口
- [ ] **同一会话重复点击不弹新窗**
  - 前置：已恢复一个会话
  - 步骤：连续快速点击同一会话行「恢复」多次（含窗口创建中的瞬间连点）
  - 预期：始终只有一个对应标题的终端窗口；创建中重复请求被忽略、创建完成后重复请求转为聚焦
- [ ] **窗口关闭后前端行状态还原（window:closed）**
  - 前置：已恢复一个会话，前端对应行显示「已打开」状态
  - 步骤：手动关闭该终端窗口，回到 kshell 等待 5~8 秒（回收宽限期 3s + 轮询间隔 2s）
  - 预期：前端该行的 open 状态自动还原为「未打开」，无需手动刷新

## SSH 连接

- [ ] **SSH 连接弹窗与聚焦复用**
  - 前置：SSH 面板中至少有一条已保存连接；本机 PATH 里有 ssh
  - 步骤：点击连接行的「连接」弹出 ssh 终端窗口；再次点击该行「连接」
  - 预期：首次弹出标题为 `kshell · <连接名>` 的终端窗口；再次点击不弹新窗，而是聚焦复用已有窗口

## 托盘

- [ ] **托盘显示/退出**
  - 前置：应用正常启动，通知区已出现 kshell 托盘图标
  - 步骤：把主窗口最小化；左键/右键托盘图标，点「显示」；再点「退出」
  - 预期：「显示」把主窗口还原到前台；「退出」移除托盘图标并结束进程（任务管理器无 kshell-desktop.exe 残留）
- [ ] **点 X 隐藏到托盘**
  - 前置：应用正常启动
  - 步骤：点击主窗口标题栏的关闭按钮 ×
  - 预期：窗口隐藏而非退出（托盘图标仍在）；经托盘「显示」可唤回；托盘「退出」可正常结束进程

## 扫描与篮子

- [ ] **会话扫描空态文案**
  - 前置：找一个没有会话的工具/目录（或临时用 `config.yaml` 的 `scan_roots` 指向空目录）
  - 步骤：启动应用等待扫描完成，查看会话列表
  - 预期：列表为空时显示明确空态文案（提示无会话及如何产生会话），而不是空白或报错
- [ ] **篮子新建会话注入**
  - 前置：Files 视图选中一个工作区
  - 步骤：勾选 2 个文件加入上下文篮（顶栏出现计数）；点「新建会话」
  - 预期：弹出的终端窗口中，CLI 的初始提示包含所勾选的文件路径

## 兼容性

- [ ] **WT 未安装回退 PowerShell**
  - 前置：模拟 Windows Terminal 缺失。**注意：仅从 PATH 剔除 WindowsApps 目录无效**——`findWt()` 在 LookPath 失败后还会回退探测 `%LOCALAPPDATA%\Microsoft\WindowsApps\wt.exe`，该路径不受 PATH 影响。有效做法是临时重命名 wt.exe（验证后还原）：
    ```powershell
    Rename-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\wt.exe" wt.exe.bak
    .\dist\kshell-desktop.exe
    # 验证完毕后：
    Rename-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\wt.exe.bak" wt.exe
    ```
    （若 wt.exe 在 PATH 的其他位置，需一并重命名或临时剔除对应目录。）
  - 步骤：在上述环境中恢复任一会话
  - 预期：弹出的是 PowerShell 窗口（非 WT），会话正常启动；还原 wt.exe 后再恢复，弹回 WT 窗口
- [ ] **深浅色主题**
  - 步骤：Windows 设置里切换深色/浅色模式，重启应用；前端界面里若有主题跟随设置也一并切换
  - 预期：两种模式下界面配色正常、无不可读的对比度问题；托盘图标在两种模式下均可见
- [ ] **TUI 照常可用**
  - 步骤：
    ```powershell
    go build ./cmd/kshell
    .\kshell.exe
    ```
  - 预期：TUI 正常启动，Sessions / Files / Remote 三视图可切换，恢复会话仍走 TUI 内嵌终端（与桌面版弹窗互不影响）

## 回归口径

- `go vet` 交叉口径为 **windows + linux** 两平台：
  ```powershell
  go vet ./...
  $env:GOOS='linux'; go vet ./...; Remove-Item Env:GOOS
  ```
- **darwin 不做 Windows 交叉验证**：托盘库 energye/systray 的 darwin 后端强依赖 cgo，Windows 上 `GOOS=darwin CGO_ENABLED=0 go vet` 恒红属于已知限制；darwin 只能在真机（开 CGO，装 Xcode 命令行工具）上构建与验证。

## 2026-09-28 UI 改造轮新增项（黑窗修复 + Tailwind/Radix 重塑 + UX 全修）

- [ ] **黑窗不闪**
  - 步骤：打开工作区页签，连续展开文件树多层目录、点开多个文件预览、切到 SSH 面板触发扫描、回首页点「重新扫描」
  - 预期：全程任务栏/屏幕不闪任何黑色控制台窗口；点「恢复/新建会话」仍正常弹出终端（该弹的窗口还在）
- [ ] **Ctrl+K 快速切换器**
  - 步骤：任意页面按 Ctrl+K；输入工作区名过滤；↑↓ 选择 + Enter；已打开时再按 Ctrl+K
  - 预期：弹出居中卡片（已开页签/工作区两组）；Enter 打开/切换对应页签；再按 Ctrl+K 关闭；数据全空显示引导文案
- [ ] **Ctrl+F 聚焦会话搜索**
  - 步骤：在工作区页签内按 Ctrl+F；在首页/设置页按 Ctrl+F
  - 预期：工作区内光标落到会话过滤框；其他页面无动作
- [ ] **页签持久化**
  - 步骤：打开 2 个工作区页签，托盘退出后重新启动
  - 预期：两个页签与激活状态原样恢复
- [ ] **右栏切页签保状态**
  - 步骤：文件树展开几层目录 → 切到 SSH → 切回文件
  - 预期：展开状态保留，不重新从根加载（无骨架屏闪现）
- [ ] **工具筛选 + SSH 历史**
  - 步骤：会话列表点工具 chip 筛选；SSH 面板执行两条命令后按 ↑，点历史 chip
  - 预期：chip 只留该工具会话（与文字搜索叠加）；输入框回填上一条命令；最近 5 条可点击回填、可清空
- [ ] **toast 反馈**
  - 步骤：恢复/新建会话（成功与人为失败各一次，如改坏 providers.yaml 指向）；连续触发 6 次失败提示
  - 预期：右下角 toast（成功绿/失败红）自动 3 秒消失；堆积超 5 条时最旧的被丢弃
- [ ] **设置页重启**
  - 步骤：改 providers.yaml 保存成功后点「立即重启」
  - 预期：新实例启动（托盘/窗口正常），旧实例进程退出
- [ ] **窗口最小尺寸**
  - 步骤：拖拽窗口边缘往小缩
  - 预期：缩到 960×640 后不再变小，布局无错乱
- [ ] **预览区入篮 / 页签中键关闭**
  - 步骤：预览一个文本文件点「加入篮子」；在打开的工作区页签上按鼠标中键
  - 预期：篮子计数 +1（文件树与预览按钮状态一致）；中键直接关闭该页签且激活邻居页签
