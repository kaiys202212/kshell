# 冒烟：feat/preview-shell-ssh

基线见 `docs/smoke/baseline-*.md`。本文件仅增量。

## 预览钉右 + 命令行子页签

1. 打开任意工作区：中心区页签条左侧为 agent 会话，**最右侧**为「预览」（样式偏 muted、有左边框）。
2. 点「预览」：内容区顶部出现子页签「预览 | +」。
3. 点「+」：新开本地终端子页签，可输入命令；再点「+」可再开一个。
4. 关闭终端子页签（×）：进程结束，退回「预览」子页签。
5. 文件树点开文件：切到预览页签且子页签落在「预览」，能看到文件内容。

## SSH 编辑与双击

1. 右栏切到 SSH：有「新建」按钮；列表行有「编辑」而非「连接」。
2. 「新建」：填主机/用户/私钥路径 → 保存 → 列表出现，来源标注「手动」。
3. 「编辑」：改用户名 → 保存 → 列表更新；可删除。
4. **双击**连接行：切到中心「预览」页签，并打开以连接名为标题的 SSH 终端子页签。
5. 非交互「执行」命令仍可用（与内嵌 SSH 终端独立）。
