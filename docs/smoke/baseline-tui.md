# kshell 冒烟清单

每次发布前在 **Windows 本机** 与 **Linux 服务器** 各跑一遍。

## 前置

```powershell
go build -o dist/kshell.exe ./cmd/kshell
```

## Sessions 视图

- [ ] 启动后顶栏显示本机实际装了的工具（已安装 ●、未安装 ○）
- [ ] 工作区列表出现最近用过的目录，按最后使用时间排序
- [ ] 选中工作区后，下方只出现该工作区的会话
- [ ] `/` 搜索：在会话聚焦时按标题过滤；切回工作区聚焦时按路径过滤
- [ ] 右栏显示选中会话的摘要（工具 / 工作区 / 更新时间 / 消息数 / ID）
- [ ] `⏎` 恢复 Claude 会话 → 进入 claude，退出后回到 kshell
- [ ] `⏎` 恢复 Codex 会话 → 进入 codex（验证 Windows `.ps1` shim）
- [ ] `n` 新建会话 → 进入工具 CLI，cwd 是选中工作区

## Files 视图

- [ ] 文件树只显示一层，`⏎` 展开目录
- [ ] `.gitignore` 与 `node_modules/.git/vendor/dist` 默认不显示
- [ ] `a` 切换「显示全部」后被忽略的文件出现
- [ ] 右栏预览：文本带行号；大文件截断有提示；二进制只显示元信息不输出乱码

## Remote 视图

- [ ] `i` 扫描：`~/.ssh/config` 与工作区 `.env*` / `application*.yml` / `Makefile` 等里的主机出现在候选列表
- [ ] 候选按置信度排序，低置信度默认未勾选；`space` 勾选、`⏎` 导入
- [ ] 导入后连接出现在列表，带来源标记；配置写入 `~/.kshell/connections.yaml`
- [ ] `x` 输入 `hostname` → 右栏显示输出与退出码
- [ ] `x` 输入一条不存在的命令 → 状态栏显示非 0 退出码
- [ ] `s` 进入交互式 shell，`exit` 后回到 kshell
- [ ] `t` 连通性测试通过后可以标记 ✓
- [ ] `b` 绑定到当前工作区；`d` 删除后列表即时更新
- [ ] 密钥不可达 / 连接超时时给出明确错误与建议，而不是挂死

## 异常路径

- [ ] 删除一个出现过的工作区目录 → 列表项不消失但不再误报错误
- [ ] 手动破坏一个会话 jsonl → 状态栏提示「N 个会话解析失败」，kshell 正常打开
- [ ] `~/.kshell/config.yaml` 写入非法 YAML → 自动备份为 `.bak` 并重建默认配置，状态栏有提示
- [ ] `PATH` 移除 ssh → Remote 视图给出「启用 OpenSSH」提示
- [ ] 窗口缩到 40×12 → 折叠为纵向单栏，无行超宽、无花屏
- [ ] `NO_COLOR=1` 启动 → 无 ANSI 颜色转义

## 性能

- [ ] 二次启动（缓存命中）1 秒内出界面
- [ ] 170+ 会话、12+ 工作区的机器上扫描 < 1s
