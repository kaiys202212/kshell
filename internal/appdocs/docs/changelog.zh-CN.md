# 升级日志

## v0.1.22 (2026-10-27)

- Claude 模型同步更省心：新装 Claude Code 时自动完成初始化引导，无需再走登录向导；同步时清理新版残留的显示名配置键，`/model` 展示真实模型不再被覆盖。
- 修复微信图片附件传输失败的问题。

## v0.1.21 (2026-10-25)

- 聊天附件全面可用：agent 回复中的图片与文件引用块回捞进时间线，附件支持点击预览与系统打开，图片落盘缓存。
- 中心区布局可配置：多页签 / 左右分割（左 agent、右文件+终端）两种模式，分隔条可拖，设置页与页签条均可快捷切换；终端重挂回放保留滚动历史。
- 新增开机自启动：设置页开关，随系统启动时静默启动到托盘。
- 品牌焕新为 Capybara：卡皮巴拉图标与显示名，「关于」分区新增开源仓库地址入口。
- 聊天气泡与 session 预览展示层还原百分号编码文件名，存储原文不动。
- Markdown 预览支持相对路径图片，经受限文件通道安全加载。
- 修复亮色主题下源码编辑器语法着色丢失。
- 升级替换改为改名交换并支持自动回滚，助手进程存活时升级仍自动拉起新版本，升级全程零打扰。
- 系统性杜绝孤儿进程：ACP 适配器、登录态探测等子进程自立进程组，退出时按组终止。
- macOS 修复：跟随系统明暗改读 AppleInterfaceStyle，文件定位改 `open -R` 选中目标。
- 修复切换页签未回收图片灯箱预览状态的问题。

## v0.1.20 (2026-10-24)

- 内置支持 TRAE CLI：工具发现、会话解析与恢复、ACP 对话、skills 与安装全流程打通；支持 `traecli login status` 登录态探测。
- 会话页签增强：溢出时自动收纳进「更多」菜单，支持拖拽排序；项目页签加宽，工作期间显示旋转动画。
- 未登录的工具不再出现在会话创建入口（CodeBuddy / TRAE 登录态探测），登录弹窗关闭后自动刷新列表。
- 模型同步健壮性：默认模型悬空自愈、同步不再挤出内置模型、ACP 下拉同名去重；Claude 同步清除悬空顶层 model，CodeBuddy 同步清理旧平台镜像模型并仅注入默认平台。
- 卸载工具前自动关闭其打开的 kshell 会话；删除失败时明确提示进程占用。
- CodeBuddy 登录态探测改用 `_codebuddy.ai/getUserInfo`，更可靠；工具分区刷新按钮改名并附操作提示。

## v0.1.19 (2026-10-23)

- 模型同步新增 Claude 目标：切换默认平台或新装 Claude 时自动静态注入 `settings.json`，并同步当前模型与平台模型别名。
- 平台模型同步扩展写入 OpenCode / CodeBuddy 自有配置。
- 修复升级检查跨源版本比较，现在会取多源中的最新版本，并纠正 GitCode latest 标记识别。
- 修复全局快捷键 Alt+Shift+K 偶尔无法注册的问题。
- AgentHub 欢迎词气泡不再显示快捷回复按钮。

## v0.1.18 (2026-10-22)

- AgentHub 待选菜单改分组结构：首项快捷新建会话，附最近 5 个会话；待选期间用户原话即时可见。
- 微信引用投递增强：让路待选并直发目标会话；归因失败时进入待选而非误发当前会话；出站消息按 SessionID 落盘归因，引用过期也能按会话恢复。
- 激活 / 新建会话期间显示「正在启动 agent」动画，等待不再无反馈。
- AgentHub / 微信完整展示末轮回复，超长内容自动拆条投递。
- AgentHub 会话胶囊始终显示项目前两字前缀，消息带绝对时间与用户归因工具名。
- Cursor 聊天支持 ACP 会话标题取首条用户提问，优先使用自带 node.exe。
- 修复 AgentHub 会话撞号串名、跨端清待选、外链弹窗改走系统浏览器、文件树监视减负并独立同步 git 色标等问题。

## v0.1.17 (2026-10-21)

- 新增设置「帮助」分区：内置双语文档「功能使用说明」与「升级日志」，随时查阅不必翻官网。
- 新版本升级完成后自动弹窗展示完整升级日志，新功能一目了然。
- AgentHub 微信桥全面增强：语音消息落盘随行转交、附件与文字合并发送、引用回复精确归因到对应会话，出站消息统一以【会话名】开头。
- AgentHub 支持 `#f` 直投最新会话；没有精确目标时列出会话待选，回复数字即可投递。
- AgentHub 会话改为输入框上方平铺 chips，点击即可 @ 对应会话；完成通知按同文去重，不再复读历史。
- AgentHub 接入自主工具与 `dispatch_task` 派发，新增路由模式开关，写操作前弹出确认卡。
- Cursor 聊天切换官方 ACP 通道，支持登录态探测与登录弹窗，未登录时给出降级提示。
- 自动发现 Cursor acp-sessions 会话，未激活会话可快捷回复激活，标题与预览从 store.db 还原。
- ACP 激活 Claude 会话时自动恢复上次使用的模型；新建会话时同步所选模型并在下次沿用。
- 修复 ACP 聊天气泡表格渲染、模型列表为空时前端崩溃、恢复会话时模型名称匹配失败等问题。

## v0.1.16 (2026-10-18)

- 微信语音回执优化：模型不支持音频输入时明确提示，并给出在设置中配置语音识别模型的指引。

## v0.1.15 (2026-10-17)

- 多模型平台支持：可配置多套模型平台（预设 / 自定义双协议地址），一键切换默认平台，会话模型下拉按「平台前缀 + 模型名」合并展示。
- AgentHub 自主工具：agent 可注册并调用本机能力（工具循环），写操作前弹出确认卡，输入路由支持自动 / 仅 agent / 强制工具三种模式。
- 微信桥：扫码绑定微信，白名单控制可用联系人，支持上下文令牌、出站消息镜像与附件转交。
- 微信语音消息支持：SILK 解码转 WAV，经 OpenAI 兼容接口转写为文字发给 agent。
- 新增 F1 帮助面板：随时查看键盘快捷键速查表。
- 修复 MCP stdio 握手超时与输出丢失问题（逐消息 Flush）。
