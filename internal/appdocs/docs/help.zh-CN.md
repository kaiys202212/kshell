# kshell 功能使用说明

kshell 是轻量级 agent 编程工具管理器，核心理念是「发现 → 选择 → 交付」：

- 自动发现本机已安装的 agent CLI（Claude Code / Codex / Gemini / OpenCode / Cursor / CodeBuddy 等）及其工作区与历史会话；
- 一键恢复或新建会话，对话能力交由各工具自身 CLI 完成，kshell 不重复实现；
- 桌面端与 TUI 双入口，功能一致，本说明以桌面端为准。

## 安装与启动

### 安装

- Windows：下载安装包（或升级包）后按向导安装。
- macOS：提供 DMG 安装包，拖入应用目录即可。
- Linux：可用仓库自带 build.sh 本地构建。

### 首次启动

- 首次运行会自动补建桌面快捷方式。
- 首次运行弹出 Agent 安装向导：检测哪些 agent CLI 尚未安装，勾选后一键安装；也可以跳过，稍后在「设置 → 工具」里补装。
- 同名应用只允许运行一个实例，重复启动会激活已有窗口。

### 主界面布局

- 左侧首页：工作区（项目）列表，是会话发现与新建的入口。
- 页签区：每个工作区一个页签，页签内含会话列表、终端、文件树、Git 面板等。
- 标题栏：首页按钮、页签切换、设置入口与窗口控制按钮。

### 关闭与升级

- 关闭窗口行为可在设置里选择「最小化到托盘」或「退出程序」。
- 最小化到托盘后，从托盘图标右键菜单可恢复窗口或退出程序。
- 手动检查更新：设置「关于」页点击「检查更新」。
- 自动检查：应用每两小时自动检查一次，发现新版本会弹窗提示。
- 升级：点击升级后自动完成下载与替换，升级完成后会弹窗展示本次完整升级日志。

## 会话管理

kshell 启动时会扫描各 agent 工具的会话目录（如 Claude Code 的 `~/.claude/projects`、Codex、Gemini、OpenCode、Cursor 等），解析会话标题与时间，按工作区聚合展示。扫描结果有本地缓存，二次打开秒级呈现，后台自动刷新。

### 发现与恢复

- 首页按工作区分组展示历史会话，附带最近活跃时间与消息数。
- 点击某个会话即可恢复：
  - 终端类工具用其自带的 resume 参数恢复原会话上下文；
  - 聊天类（ACP）工具直接恢复对话记录。
- 会话列表支持按关键字搜索，也可按工具筛选。

### 新建会话

- 首页「新建会话」：选择工具与工作区即可启动。
- 也可在会话列表空白处或右栏 Terminal 面板的新建入口发起。
- 上次用过的「工具 + 项目」组合会被记住，下次可直接沿用。
- 会话页签名称重复时自动去重显示，避免混淆。

### 批量与归档

- 会话列表左上角进入多选模式，可全选后一键「批量归档 / 批量恢复」，适合清理积压的旧会话。
- 不再活跃的会话可归档收纳，归档后从主列表隐藏，需要时可再恢复。
- 归档建议：会话结束一段时间后会自动提示是否归档。

### 工作区管理

- 首页支持添加本地项目目录、新建项目（本地或远程）。
- 项目可删除或移入回收站；误删可从回收站一键恢复。
- 首页支持按名称 / 路径筛选工作区，项目多时快速定位。

## 终端页签

- 每个工作区右侧栏有 Terminal 面板，点击加号可新建本地 shell 页签，支持同时开多个。
- 终端基于 ConPTY（Windows）/ PTY，与真实终端行为一致。
- agent 会话也以终端页签形式呈现，运行状态实时可见。
- 终端页签支持拖拽排序、Ctrl+W 关闭；退出后页签保留退出码提示。
- 纯 shell 终端会注入主题环境变量，终端内深浅色与应用主题保持一致。
- 文件可直接拖入终端或聊天输入框，自动转为路径。

## 文件树与预览编辑

工作区左侧为文件树，右侧为文件页签区，支持同时打开多个文件。

### 文件树

- 支持新建 / 重命名 / 删除文件与文件夹，删除有二次确认。
- 支持复制路径、在系统资源管理器中显示。
- 树内支持按名称过滤；也可对整个工作区做全文搜索，结果按文件分组。
- 右键可把文件 / 目录加入 ignore（写入 .gitignore）。
- Git 状态角标（新增 / 修改 / 删除 / 冲突）实时更新在文件树上。

### 预览

- Markdown：「预览 / 源码」模式一键切换；预览支持关键词高亮检索，可跳转上一个 / 下一个匹配。
- HTML：在应用内浏览器页签中渲染预览，也可选择用系统浏览器打开。
- 图片、PDF 直接预览（PDF 支持翻页）；二进制文件提示不可预览。

### 编辑

- 文本文件在 CodeMirror 编辑器中打开，支持语法高亮。
- 查找面板支持文件内搜索 / 替换（CodeMirror find panel）。
- 保存即写盘；未保存关闭会提示确认。
- 外部修改实时监听，自动刷新内容。

## Git 面板

工作区内置 Git 面板，无需切换到命令行即可完成日常操作。

### 状态页签

- 展示未提交变更，按「已暂存 / 未暂存」分组。
- 支持单文件或全部的暂存 / 取消暂存 / 丢弃（丢弃有二次确认）。
- diff 视图内可按块（hunk）暂存 / 取消暂存 / 丢弃。
- 输入提交信息后可「提交」或「提交并推送」。

### 提交图与 diff

- 图形化展示当前分支提交历史，触底自动分页加载更早历史。
- 点击任意提交即可在 diff 页签中查看该次提交的完整变更。

### 同步与分支

- 面板工具栏提供拉取（pull）、获取（fetch / fetch all）、推送（push）。
- 储藏（stash）：支持暂存改动、恢复最近一次、丢弃指定储藏（有确认）。
- 分支：可查看当前分支与本地 / 远程分支列表，支持切换与新建分支。
- 操作进行中显示 busy 转圈，完成后有结果提示。
- 面板顶部显示分支名与未提交变更数角标；非 Git 目录会明确提示。

## 远程 SSH 管理

### 连接管理

- SSH 面板列出所有连接，双击即打开远程终端。
- 支持手动新建连接：名称 / 主机 / 用户 / 端口 / 密钥路径 / 密码。
- 私钥只保存路径引用，不存储私钥内容；面板内明文密码有明确提示。
- 连接支持编辑与删除。

### 连接导入

- 点击「导入」可自动扫描本机既有配置：ssh config、Xshell 等客户端。
- 勾选扫描结果后批量导入，无需逐条手填。

### 远程会话与远程工作区

- 远程主机上发现的 agent 会话同样出现在会话列表，可远程恢复；不可达的远程会话会明确标记。
- 首页「新建会话」可选远程位置：远程目录浏览器选好路径后，即可像本地一样打开远程工作区（文件树 / 编辑 / 终端）。
- AllowAgent 白名单：SSH 面板可为每条连接设置允许访问的 agent 白名单。
- 桌面端会自动为远程会话注入 kshell-ssh MCP 与本机 Hub，让远程 agent 能使用本机能力。

## AgentHub

AgentHub 是多 agent 协作面板：在一个视图中同时运行多个 agent 会话，用自然语言分派任务、互相可见。

### 新建与发消息

- 面板内「新建 agent」选择项目与工具；需先在设置里完成默认配置。
- `/easynew` 命令用上次的项目与工具配置快速创建。
- 输入框直接输入即发给当前目标；`@` 可指定某个 agent 为目标（未指定时自动路由）。
- 消息入队有 ack 提示（已送达 / 已排队）；消息支持撤回。

### 命令

输入以 `#` 开头可调出命令面板：

- `/new`：新建 agent；
- `/easynew`：用上次配置快速新建；
- `/stop`：停止目标 agent；
- `/model`：切换模型；
- `/clear`：清空本视图；
- `/find`：查找并激活已发现的会话。

### 输入路由模式

会话栏可切换三种路由模式：

- 自动：短语命令优先走工具，其余交给 agent；
- 仅 agent：把一切输入交给 agent 自行理解；
- 强制工具：优先匹配内置命令。

### 确认卡与会话管理

- agent 请求执行写操作（写文件、执行命令等）时弹出「待确认操作」卡片，批准或拒绝后才继续，安全可控。
- 面板侧栏列出 Hub 内全部会话，可跳转、关闭。
- 视图可开启自动滚动跟随输出。

## 微信桥

绑定微信后，可以在微信里查看 agent 回复并发送指令，桌面端始终是主视角。

### 绑定

- 设置「微信」分区点击「绑定微信」，用微信扫码并确认即自动完成绑定。
- 页面实时显示运行状态；断开时提示重新绑定。

### 白名单与收发

- 只有白名单内的微信用户可以使用桥接功能，避免陌生人滥用；绑定者本人默认可用。
- 微信里发消息即转发给 agent，回复镜像回微信（出站镜像）。
- 图片等附件自动转交 agent。

### 语音转写

- 微信语音消息自动解码（SILK → WAV）并经 OpenAI 兼容 ASR 接口转写成文字再发给 agent。
- 需在「设置 → 模型」为所在平台配置转写模型（ASR Model）；未配置时回落到默认对话模型。
- 若当前模型不支持音频输入，微信里会收到明确的回执与配置指引。

## 设置

设置页左侧导航分五个分区：通用 / 微信 / 模型 / 工具 / 技能广场。

### 通用

- 外观：跟随系统 / 亮色 / 暗色；界面字号；显示空白符。
- 界面语言：English / 简体中文 / 跟随系统。
- 关闭窗口行为：最小化到托盘 / 退出程序。
- 默认会话模式：TUI（终端）/ ACP（聊天）；工具不支持 ACP 时即使选了 ACP 也会走终端。
- 权限模式：默认（需确认）/ Bypass（跳过确认）。Bypass 会自动放行 CLI 与 ACP 的权限弹窗，仅建议在可信环境使用。
- 通知提示音开关。

### 模型（多平台）

- 可添加多套模型平台：内置预设或自定义，分别填写 OpenAI / Anthropic 双协议 Base URL 与 API Key。
- 每个平台可维护模型列表：可从平台拉取后按关键字筛选，也可手动增删。
- 指定一台默认平台；会话内的模型下拉按「平台前缀 + 模型名」合并展示所有平台的模型，切换即时生效。
- 可为平台配置语音转写模型（ASR Model），供微信桥语音消息使用。

### 工具

- 列出本机检测到的所有 agent CLI 及其状态：正常 / 未安装 / 损坏 / 仅配置。
- 支持一键安装、卸载、修复；卸载可选择是否同时清理配置。
- 「重新扫描」可在手动安装后刷新状态。

### 技能广场

- 搜索 skills.sh 上的 agent 技能并一键安装到本机工具。
- 安装前展示文件预览与信任提示，可选安装目标。
- 支持卸载与覆盖安装（force overwrite）。

### 关于与升级 / 帮助

- 关于：显示当前版本，手动检查更新，发现新版本可立即升级；提供反馈问题入口。
- 帮助：内置「功能使用说明」与「升级日志」双语文档（即本页面）。
- 升级到新版本后会自动弹窗展示完整升级日志。

## 快捷键

按 F1（或设置内帮助入口）可随时打开快捷键速查面板，Esc 或再按 F1 关闭。

| 快捷键 | 功能 |
|---|---|
| Ctrl+K | 打开 / 关闭页签与工作区快速切换器 |
| Ctrl+F | 聚焦当前视图的搜索框 |
| Ctrl+1..9 | 切到第 N 个已打开页签（越界忽略） |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个页签 |
| Ctrl+W | 关闭当前工作区页签 |
| Ctrl+0 | 回到首页（新建会话入口） |
| Ctrl+T | 回到首页（终端聚焦时让行给终端语义） |
| F1 | 显示 / 隐藏快捷键速查表 |

说明：终端（xterm）聚焦时，写终端的快捷键（如 Ctrl+K、Ctrl+F、Ctrl+W、Ctrl+T）自动让行给终端语义，只有切页签类快捷键仍然生效，避免一次按键双重效应。
